# sossa# 🌟 Profile Card Project

This project is a simple, accessible, and responsive **Profile Card** built with **semantic HTML**, **modern CSS**, and a little **vanilla JavaScript**.  
It displays a user’s name, bio, avatar, hobbies, dislikes, social links, and the current time in milliseconds.

---

## 🧩 Features

- Semantic HTML structure for accessibility  
- Responsive layout (works perfectly on mobile, tablet, and desktop)  
- Live time display using `Date.now()`  
- Avatar image with alt text  
- Social links that open in new tabs  
- Keyboard-accessible navigation  
- Modern Flexbox/Grid design
